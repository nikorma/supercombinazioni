SUPERCOMBINAZIONI PWA v9

Novità:
- layout completamente nuovo e più pulito
- 5 sezioni: Home, Genera, Verifica, Statistiche, Archivio
- history.json separato dall'interfaccia
- GitHub Action che costruisce lo storico dal 1997
- aggiornamento automatico nei giorni di estrazione
- ricerca per anno/data/numero
- verifica sestina duplicata
- 2/3/4/5/5+1/6 storico
- pari/dispari, distanze e legami

PRIMA PUBBLICAZIONE
1. Carica TUTTI i file e le cartelle nel repository.
2. In GitHub apri Actions.
3. Seleziona "Update historical archive".
4. Run workflow, lasciando attivo "Ricostruisci tutto lo storico dal 1997".
5. Attendi il commit automatico di history.json.
6. GitHub Pages si aggiornerà con lo storico.

La sorgente ufficiale superenalotto.it viene preferita. Quando un anno non è esposto nelle pagine mensili ufficiali, lo script usa l'archivio annuale indipendente national-lottery.com come fallback.
